
# Juego del Ahorcado

## Descripción
Juego del ahorcado desarrollado con PHP, HTML y CSS.

## Funcionamiento
El juego selecciona una palabra aleatoria de una lista de animales.

El jugador debe adivinar la palabra introduciendo letras.

Tiene un máximo de 6 vidas. Cada fallo resta una vida.

Si descubre la palabra, gana. Si se queda sin vidas pierde.

## Como ejecutar el juego
1. Iniciar Apache desde XAMPP
2. Guardar los archivos en la carpeta htdocs
3. Abrir el juego desde localhost en el navegador

## Tecnologias utilizadas
-PHP,HTML,CSS,Git y GitHub
